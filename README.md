# PGF Portfolio

## PGF-Free-Knowledge

**Ingeniería aplicada · Gestión energética · Inteligencia Artificial · Machine Learning · Automatización · SCADA · Instrumentación · Adquisición de datos · Analítica · Investigación · Desarrollo tecnológico**

Repositorio principal destinado a organizar y presentar el conjunto de proyectos, desarrollos técnicos, profesionales, académicos y de investigación desarrollados dentro de **PGF-Free-Knowledge**.

Este repositorio funciona como punto central de navegación del trabajo desarrollado en diferentes áreas de la ingeniería, manteniendo cada proyecto especializado en su correspondiente repositorio.

---

# 1. Propósito

`PGF_Portfolio` reúne proyectos relacionados con ingeniería aplicada y transformación de datos en información útil para análisis, predicción y toma de decisiones.

El portafolio integra distintas etapas:

**Ingeniería → Medición → Adquisición → Datos → Analítica → Modelación → Machine Learning → Predicción → Visualización → Aplicación**

# 6. Inteligencia Artificial aplicada

La Inteligencia Artificial se considera una herramienta tecnológica que puede integrarse con sistemas reales y datos de ingeniería.

Una solución aplicada puede requerir:

1. Obtención de datos.
2. Preparación de información.
3. Selección de variables.
4. Desarrollo del modelo.
5. Evaluación.
6. Predicción.
7. Interpretación.
8. Visualización.
9. Integración con una aplicación.
10. Apoyo a la toma de decisiones.

Por esta razón, IA y Machine Learning forman parte de una arquitectura tecnológica mayor.

# 8. Repositorios independientes

Los proyectos contenidos dentro de `PGF_Portfolio` mantienen sus propios repositorios Git.

El repositorio principal utiliza **Git submodules** para mantener esta estructura.

Esto permite:

- Mantener cada proyecto como repositorio independiente.
- Conservar su historial Git.
- Mantener documentación propia.
- Desarrollar cada proyecto independientemente.
- Organizar todos los proyectos desde un punto central.

Por tanto:

**PGF_Portfolio** presenta la visión global.

**Cada repositorio individual** contiene el desarrollo específico.
