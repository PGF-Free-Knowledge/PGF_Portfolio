# PGF Dashboard — Python / VS Code

Dashboard interactivo para la demostración de la charla.

## Ejecución en VS Code

```bash
pip install -r requirements.txt
streamlit run app/app.py
```

El dashboard separa claramente:
1. Desempeño
2. Predicción
3. XAI / SHAP
4. Escenarios

Los datos son los del demo ML sintético utilizado en el notebook; no deben presentarse como mediciones de Oil Malal.
