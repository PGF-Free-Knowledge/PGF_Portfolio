# PGF Dashboard v004

Dashboard interactivo para la charla, desarrollado en Python + Streamlit.

## Ejecución en VS Code

```powershell
python -m streamlit run app\app.py
```

## Flujo
1. Desempeño: filtro temporal + consumo.
2. Predicción: Real vs. Predicho + residuales + MAE/RMSE/R².
3. XAI/SHAP: importancia global + explicación local de una observación.
4. Escenarios: comparación Base vs. Escenario + variación.

Los datos corresponden al demo ML sintético del notebook y no deben presentarse como mediciones de Oil Malal.
