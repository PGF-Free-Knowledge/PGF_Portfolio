# PGF Dashboard — Python / VS Code

Dashboard interactivo para la demostración de la charla.

## Ejecución
```bash
python -m streamlit run app\app.py
```

## Módulos
1. Desempeño energético
2. Predicción — Real vs. Predicho
3. XAI — SHAP
4. Escenarios interactivos

La versión actual incorpora una interfaz visual profesional, KPIs y navegación para demo en vivo.
Los datos corresponden al demo ML sintético; no deben presentarse como mediciones de Oil Malal.
